# 配信ノート Stream Notes for OBS 使用方法

対象バージョン: 1.0.0  
対応環境: Windows 10／11 64bit、OBS Studio

## 1. 配信ノートについて

配信ノートは、AIが出力した文章、Markdown、テキストファイルを、OBS Studioのブラウザーソースで読みやすい配信画面へ変換する無料アプリです。

入力した文書は利用者のPC内に保存され、外部サーバーへ送信されません。利用状況の計測、広告、テレメトリーもありません。

## 2. ダウンロードと確認

BOOTHまたはGitHub Releasesから、次のZIPをダウンロードします。

```text
stream-notes-v1.0.0-windows-x64.zip
```

配布元が掲載しているSHA256と、ダウンロードしたZIPの値が一致することを確認できます。

```powershell
Get-FileHash ".\stream-notes-v1.0.0-windows-x64.zip" -Algorithm SHA256
```

値が一致しない場合は実行せず、公式配布元からダウンロードし直してください。

## 3. 起動と終了

1. ZIPを任意のフォルダーへ展開します。
2. ZIP内から直接実行せず、展開後のフォルダーを開きます。
3. `start-stream-notes.cmd`をダブルクリックします。
4. ブラウザーで操作画面が開けば起動成功です。

Node.jsランタイムを同梱しているため、Node.jsの追加インストールは不要です。

終了するときは`stop-stream-notes.cmd`をダブルクリックします。ブラウザーを閉じるだけではサーバーは終了しません。

デスクトップへ起動アイコンを作る場合は、`install-desktop-shortcut.cmd`を一度実行します。

## 4. 文書を追加する

### 直接入力

中央の入力欄へ文章を入力します。入力内容は自動保存されます。

### クリップボードから追加

AIの回答などをコピーしてから「貼り付けて追加」を押します。新しい文書としてライブラリーへ追加されます。

### ファイルから追加

「ファイル追加」から`.md`、`.markdown`、`.txt`を選択します。複数ファイルをまとめて追加できます。

文書は左側のライブラリーから検索、選択、複製、削除できます。削除した文書は元に戻せないため、重要な原稿は別途バックアップしてください。

## 5. 文書の書き方

### 見出しと箇条書き

```markdown
# 配信タイトル

## 今回の要点

- 最初に伝えること
- 次に詳しく説明すること
```

見出し単位で配信ページへ分割されます。文章量が多い場合は、同じ見出しの中でも複数ページになります。

### 表

```markdown
| 項目 | 値 | メモ |
| --- | ---: | --- |
| GPU稼働率 | 82% | 高水準 |
| 冷却効率 | 68% | 改善余地あり |
```

Markdown表は配信画面用の表へ変換されます。長い表は文字を小さくせず、内容部分をスクロールできます。

### 数値データ

```markdown
- GPU稼働率: 82%
- 冷却設備効率: 68%
- 送電余力: 44%
```

数値を含む項目は、内容に応じてキーデータや比較表示に利用されます。

### 数式

文中の数式はドル記号1つで囲みます。

```markdown
消費電力は $P = N \times W$ と表せます。
```

別行立て数式はドル記号2つで囲みます。

```markdown
$$
E = P \times t
$$
```

数式はKaTeXで表示されます。

AI出力の`**[ \\frac{\\text{SRAM面積}} {\\text{Chip総面積}} ]**`形式も、バックスラッシュが1つでも2つでも別行立て数式へ自動変換します。

角括弧の開始と終了が別段落に分かれている場合も結合され、途中の太字記号、連続した`====`、添字用にエスケープされた`\_`を数式向けに整えます。

### ASCII図

図はコードブロックで囲みます。

````markdown
```text
GPU / Switch ASIC
       |
       v
Optical Transceiver
       |
       v
     Fiber
```
````

コードフェンスの`text`は配信画面へ表示されません。長い図は内容部分を上下にスクロールできます。

## 6. 表示を調整する

- `文字量`: 1ページに表示する文章量を変更します。
- `文字サイズ`: 標準、大、特大から選択します。
- `自動送り`: 指定秒数ごとに次のページへ進みます。
- `テロップ`: 画面下部の要点テロップを表示します。
- `画面を隠す`: 原稿を編集中にOBS表示を一時的に隠します。
- `ページスライダー`: 多数のページをドラッグしてすばやく移動します。
- `ページ番号`: 移動先を入力してEnterキーを押すと、そのページへ直接移動します。
- 上下ボタン: 長い表や図をスクロールします。

前後の矢印でページを移動できます。テロップは最後まで流れた後、先頭から再開します。

## 7. OBS Studioへ追加する

1. 操作画面の「URLコピー」を押します。
2. OBS Studioの「ソース」にある`+`を押します。
3. 「ブラウザ」を選択します。
4. コピーしたURLを貼り付けます。
5. 幅`1920`、高さ`1080`、FPS`60`に設定します。

表示URLは次の通りです。

```text
http://127.0.0.1:4177/?view=overlay
```

文字がぼやける場合は、OBS側で次を確認します。

- ブラウザーソースを1920x1080にする
- OBSの変換をリセットする
- 同じURLのブラウザーソースを重複表示しない
- 必要に応じてブラウザーのキャッシュを更新する
- 出力縮小フィルターにLanczosを使用する

## 8. ポインターと描画

### ポインター

「ポインター」を有効にし、矢印、レーザー、スポットから選択します。操作画面とOBS表示の座標は1920x1080基準で同期します。

OBSの「相互作用」画面から直接操作することもできます。

### 配信メッセージ

質問、注目、回答から種類を選び、短いメッセージを配信画面へ表示できます。

### 描画

「描画」を有効にし、ペン、マーカー、消しゴムを選択します。色と太さを変更でき、取り消しとページ単位の消去にも対応しています。

## 9. 保存、更新、削除

文書は次の場所へ保存されます。

```text
%LOCALAPPDATA%\StreamNotes\state.json
```

アプリ本体と文書データは別の場所にあるため、新しいZIPを別フォルダーへ展開しても文書は引き継がれます。

更新するときは、旧版を`stop-stream-notes.cmd`で終了してから、新しいZIPを展開して起動します。

アプリを削除するときは、アプリのフォルダーを削除します。文書も完全に削除する場合だけ、アプリ終了後に`%LOCALAPPDATA%\StreamNotes`を削除してください。

## 10. トラブル対応

### 操作画面が開かない

ブラウザーで`http://127.0.0.1:4177/`を直接開きます。それでも開かない場合は、別のアプリがポート4177を使用していないか確認します。

### OBS表示が更新されない

OBSのブラウザーソースを右クリックし、「ブラウザのキャッシュを更新」を実行します。

### 文書が見つからない

左側の検索欄を空にし、文書一覧を確認します。保存ファイルを手動編集する前にバックアップを作成してください。

### 起動ファイルがセキュリティソフトに止められた

無理に実行せず、ZIPのSHA256と配布元を確認してください。値が異なる場合は削除して、公式配布元から入手し直します。

## 11. プライバシーとライセンス

- 入力文書を外部へ送信しません。
- 利用状況の計測、広告、テレメトリーはありません。
- OBSとの同期は同じPC内の`127.0.0.1`だけで行います。
- ポート4177をLANやインターネットへ転送しないでください。
