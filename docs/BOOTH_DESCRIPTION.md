# BOOTH商品ページ用文章

## 商品名

配信ノート Stream Notes for OBS（Windows版）

## 価格

0円

## 紹介文

AIが出力した文章、Markdown、テキストファイルを、OBS Studioのブラウザーソースで読みやすい配信画面へ変換する無料アプリです。

文章を貼り付けるだけで見出しや箇条書きをスライド化し、Markdown表、数値グラフ、ASCII図、KaTeX数式を表示できます。長い表や図は文字サイズを保ったままスクロールできます。

ポインター、レーザー、スポットライト、配信メッセージ、ペン、マーカー、消しゴム、循環テロップ、自動送りにも対応しています。

## 動作環境

- Windows 10／11 64bit
- OBS Studio
- 1920x1080、60 FPS推奨
- インストール不要、Node.jsランタイム同梱

## 使い方

1. ZIPを展開
2. `start-stream-notes.cmd`を実行
3. 操作画面で「URLコピー」
4. OBSのブラウザーソースへURLを設定

詳しい手順はZIP内の`README.txt`にあります。

## データと通信

入力文書は利用者のPC内へ保存され、外部サーバーへ送信されません。利用状況の計測や広告もありません。
