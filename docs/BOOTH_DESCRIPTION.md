## 商品名

配信ノート Stream Notes for OBS（Windows版）

## 価格

0円

## 商品紹介文の概要

配信ノート Stream Notes for OBSは、AIが出力した文章、Markdown、テキストファイルを、OBS Studioで読みやすい配信画面へ変換するWindows向け無料アプリです。

文章を貼り付けるだけで見出しや箇条書きを配信用ページへ変換し、Markdown表、数値グラフ、ASCII図、KaTeX数式を表示できます。長い表や図は、文字サイズを保ったままスクロールできます。

ページスライダーと番号指定による直接移動、ポインター、レーザー、スポットライト、配信メッセージ、ペン、マーカー、消しゴム、循環テロップ、自動送りにも対応しています。

## 動作環境

- Windows 10／11 64bit
- OBS Studio
- 1920x1080、60 FPS推奨
- バージョン1.0.0
- ダウンロードサイズ約34.3MB
- インストール不要、Node.jsランタイム同梱

## 起動とOBSへの追加

1. ZIPを任意のフォルダーへ展開する
2. `start-stream-notes.cmd`を実行する
3. 操作画面で「URLコピー」を押す
4. OBSのブラウザーソースへURLを設定する

デスクトップへ起動アイコンを作る場合は、ZIP展開後に`install-desktop-shortcut.cmd`を一度実行します。初回起動だけではアイコンは自動作成されません。

簡易手順はZIP内の`README.txt`、詳しい手順は`USER_GUIDE.md`と商品ページに添付する使用方法PDFにあります。

入力文書は利用者のPC内へ保存され、外部サーバーへ送信されません。利用状況の計測、広告、テレメトリーもありません。
